## Corrections and terminology

1. The name “Kusner’s conjecture” is ambiguous after 2026: it has a taxicab branch $p=1$, predicting $2n$, and a finite-$p>1$ simplex branch, predicting $n+1$. Chalmers disproves part of the latter; this project concerns only the former.
2. The original Guy article is pp. **196–200** in publisher/Crossref metadata. Several older bibliographies abbreviate it as pp. 196–199. We retain the publisher/Crossref range and explicitly note the access limitation on the original problem text.
3. OCR often renders Petty’s $2^n$ as “2n.” The mathematically correct universal bound is $2^n$, not $2n$.
