# LaTeX source

This archive builds the paper *The Largest Cyclic 3-(31,5,1) Packing Has
Twelve Base-Block Orbits*.

Required files:

- `main.tex`
- `references.bib`

Build with TeX Live 2026 (or a compatible distribution):

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The included `main.bbl` is the bibliography generated by BibTeX. No proof
assistant was used. The exact computational certificates and independent
verifiers are distributed in the parent research project, not duplicated in
this compact manuscript-source archive.
