`thm:xy-box`.  Paths below are relative to the package root.  Every cell has
one source script, source note, source normal result, source manifest,
independent referee script, referee result, referee report, and referee
manifest: eight files per cell, 32 grouped files in total.

`0<h<=1`, and every `lambda>0`.  Each has `531/531` strict exact trivariate
Bernstein controls and a `71/71` exact left seam.  The four cells are joined
at `x=627/1000`, `x=63/100`, and `x=16/25`; the first also joins the frozen
v17 predecessor at `x=313/500`.

## Historical manifest anchors (not a portable replay)

The eight manifests listed among the 32 principal artifacts are preserved
byte-for-byte as historical provenance.  After machine-specific generated
transcripts were intentionally omitted, those old manifests name 113 unique
files not present in the compact package.  Consequently, running their old
`shasum -c` commands is expected to report missing files; those commands are
not a portable verification gate.

Use `../xy_box_post_v17_portable/README.md` instead.  Its four source, four
referee, four cell, and top portable manifests bind fresh relative-path runs,
proof inputs, fail-closed attacks, and package-local verifiers.  The 32
principal bytes above remain the historical theorem artifacts, while the
parallel layer supplies the self-contained replay chain.
