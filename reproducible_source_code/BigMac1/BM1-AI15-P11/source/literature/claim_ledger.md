## Corrections to the supplied background

1. The historical problem explicitly includes trees **or perhaps forests**;
   this project keeps the requested tree core primary and labels forest facts as
   adjacent results.
2. The phrase “all these trees are still unimodal” is fully certified for the
   enumerated trees through order 30, but was not found as a proved statement
   covering every member of every post-2023 infinite non-log-concave family.
3. The order-30 frontier is a 2026 exact computational artifact hosted through
   SciNet with a recorded independent reproduction. The largest located
   archival/published record before it is Reynolds' Zenodo v3 result through
   order 29; the distinction is retained throughout.
