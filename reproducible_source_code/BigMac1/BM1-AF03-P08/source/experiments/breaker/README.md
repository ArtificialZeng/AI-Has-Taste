# Breaker route: exact exhaustive search

This directory is the discovery implementation for the counterexample-first
route.  It is deliberately separate from any later certificate/verifier.

## Mathematical conventions

- Permutations use one-line notation and are multiplied on the right by
  `s_i`, so `s_i` swaps positions `i` and `i+1`.
- `Omega_n = s_2 s_1 s_3 s_2 ... s_{n-1} s_{n-2}` is the fixed reduced
  expression of `v_n = 34...n12`.
- Every element of `[e,v_n]` is enumerated from all subwords of `Omega_n`.
  As an independent top-interval check, the same set is reconstructed by a
  downward BFS through the exact Bruhat cover relation.
- For each upper endpoint `v`, a retained reduced word of `v` is used to
  enumerate `[e,v]` by all of its subwords.  Thus every comparable pair is
  visited exactly once.
- The Dyer recurrence is evaluated with nonnegative integers only.  If
  `d = ell(v)-ell(u)`, the stored vector `(a_0,...,a_r)` means

      Rtilde_{u,v}(q) = q^d (a_0 + a_1 q^{-2} + ... + a_r q^{-2r}).

  In this normalization the non-descent recurrence is

      P_{u,v}(t) = P_{u,vs}(t) + t P_{us,vs}(t),  t=q^{-2}.

- Allowed factors are exactly the nontrivial members `F_h(t)`, `h >= 2`,
  generated by `F_0=F_1=1` and `F_h=F_{h-1}+t F_{h-2}`.  `F_0`, `F_1`, and
  the empty product all equal one.  Since the largest possible `t`-degree is
  eight at `n=10`, only `2 <= h <= 17` can occur.  The program exhaustively
  constructs every multiset product of those factors of total degree at most
  eight and compares integer coefficient vectors exactly.  A witness list of
  factor indices is retained for every accepted vector.

The coefficient store uses 32-bit unsigned integers only as a compact exact
representation.  Every addition and product is first performed in 64 bits
and the program aborts before storage if the result exceeds `UINT32_MAX`.
The run summary reports the largest coefficient actually encountered.

## Reproduction

From the project root:

```sh
c++ -std=c++20 -O3 -Wall -Wextra -pedantic \
  experiments/breaker/exhaustive_rtilde.cpp \
  -o experiments/breaker/exhaustive_rtilde
experiments/breaker/exhaustive_rtilde experiments/breaker/run_summary.json \
  results/breaker_candidates.json
```

The second output is created only if at least one rejected pair is found.  A
rejected pair is a discovery candidate, not a certificate.

The small-rank independent audit uses a different universe/comparability
enumerator, an uncompressed polynomial recurrence, and exact polynomial
division instead of the product catalog:

```sh
python3 experiments/breaker/independent_crosscheck.py \
  experiments/breaker/python_crosscheck.json
```
