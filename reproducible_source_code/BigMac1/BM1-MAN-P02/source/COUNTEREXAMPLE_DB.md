# Project counterexample and obstruction database

No counterexample to the rank-10 conjecture is currently known in this
project.  The entries below are route obstructions, not graph
counterexamples.

## RG10-O01: direct 63rd vertex on the five standard equality graphs

- **Claim tested:** add one vertex to a fixed 62-vertex standard graph while
  keeping adjacency rank 10 and reducedness.
- **Exact test:** enumerate all `2^10` binary profiles relative to a
  nonsingular principal core and enforce isotropy, binary adjacency to every
  old vertex, nonzero profile, and nonduplication.
- **Outcome:** zero accepted profiles for each of `aaaa`, `caaa`, `ccaa`,
  `ccca`, and `cccc`.
- **Consequence:** this direct extension route is closed for the five fixed
  inputs.  It does not rule out replacements, multi-vertex deformations, or
  a different core.

## RG10-O02: fixed standard core cannot support 63 compatible profiles

- **Claim tested:** retain the explicit ten-vertex core appearing in the
  `aaaa` equality graph and choose any compatible nonzero binary isotropic
  profiles.
- **Exact discovery outcome:** the finite compatibility graph has clique
  number 62; equality is realized.
- **Audit state:** independent integer reconstruction, exhaustive small-graph
  clique-engine comparison, randomized cross-checks, and six fail-closed
  mutations all pass.
- **Consequence:** every rank-10 reduced graph containing this particular
  induced nonsingular core has order at most 62.  Other cores remain open.

## RG10-O03: all single-edge deformations of the standard core

- **Claim tested:** toggle each of the 45 possible core edges once and seek a
  compatible clique of 53 noncore profiles, which together with the ten core
  columns would give order 63.
- **Exact discovery outcome:** 9 toggled cores are singular.  For every one
  of the other 36, exact branch-and-bound rejects a 53-profile noncore clique;
  every greedy lower witness has size 52.
- **Frozen discovery file:** `work/builder/core_single_toggle_exact.json`,
  SHA-256 `8547ec334a096bbaa33a9fd0c6ffb08fecf52796223e3274a9d95192113887a3`.
- **Independent audit:** `work/linear_extension/single_toggle_family_audit.json`,
  SHA-256 `b3363fa92066919e128582842daf1ddda8f89596e663aeb59bcf58d22028e39b`,
  reconstructs all 45 labelled toggles without importing discovery code,
  obtains the same 9 singular and 36 nonsingular split, and independently
  excludes every target clique after deterministic cyclic relabelling.
- **Consequence:** no single-edge deformation supplies a rank-10 order-63
  counterexample.  This is now a certified structural theorem, while the
  unrestricted rank-10 problem remains open.

## RG10-O04: disconnected graphs cannot be counterexamples

- **Claim tested:** a disconnected reduced graph of adjacency rank ten could
  have order at least 63.
- **Exact reduction:** every component is reduced, has rank at least two, and
  component ranks add to ten.  Applying the published exact maxima through
  rank nine to all eleven partitions of ten gives maximum order 32, at the
  partition `8+2`.
- **Audit:** `proof/connected_reduction.md` and
  `work/linear_extension/structural_theorems_audit.md` (`0 fatal / 0 major /
  0 minor`).
- **Consequence:** the disconnected route is closed.  Any counterexample is
  connected and may be searched through connected nonsingular ten-vertex
  induced cores, using the Wang--Guo theorem.

## RG10-O05: nonsingular ten-vertex tree cores

- **Claim tested:** a 63-vertex reduced rank-10 graph can contain a
  nonsingular induced ten-vertex tree as its full-rank principal core.
- **Complete discovery domain:** all 106 nonisomorphic free trees on ten
  vertices, generated by canonical leaf extension and cross-checked against
  the classical rooted/free tree-count sequences.
- **Exact outcome:** 15 trees are nonsingular, all with determinant `-1`;
  each exact profile compatibility graph has a 52-clique lower witness and
  no 53-clique after a complete target search.  Total search size is 882,626
  nodes.
- **Frozen artifact:** `work/builder/tree_core_exact_search.json`, SHA-256
  `1bdc9e089030ae02b67042e437fcb5cc9249cd841aeb85fac4cfc4858d4072d4`.
- **Audits:** deterministic no-import replay verifies all 106 trees and all
  882,626 source nodes; a separately implemented engine changes the tree
  representative and cyclically relabels every compatibility graph, closes
  all 15 targets in 760,220 calls, and passes 1,500 brute-force small-graph
  tests.  Wrong hash, dropped tree, altered edge list, and flipped conclusion
  are all rejected.
- **Consequence:** this route is closed as an exact structural theorem:
  every reduced rank-10 graph containing a nonsingular induced ten-vertex
  tree core has at most 62 vertices.  Cyclic cores remain open.

## RG10-O06: all double-edge deformations of the standard core

- **Complete discovery domain:** all `binom(45,2)=990` labelled choices of
  two toggled off-diagonal positions of the standard starlike core.
- **Exact outcome:** 346 cores are singular.  For all 644 nonsingular cores,
  exact integer profile construction followed by 81,819,391 target-search
  nodes excludes a 53-profile noncore clique; every greedy lower witness has
  size 52 and no 63-vertex candidate appears.
- **Frozen chunks:** `work/builder/core_double_toggle_first200_exact.json`,
  `work/builder/core_double_toggle_200_499_exact.json`, and
  `work/builder/core_double_toggle_500_989_exact.json`.
- **Audit state:** aggregate independent replay is pending.  This discovery
  does not replace the global connected-core search.

## RG10-O07: all connected unicyclic ten-vertex cores

- **Claim tested:** a 63-vertex reduced rank-10 graph has a nonsingular
  induced connected unicyclic principal core on ten vertices.
- **Complete domain:** 657 nonisomorphic graphs.  Tree-plus-nonedge and
  rooted-tree-decorated-cycle generation give the same canonical set.
- **Exact outcome:** 521 cores are singular; for all 136 nonsingular cores,
  exact integer compatibility construction and 9,987,213 discovery search
  nodes exclude a 53-profile noncore clique.  No counterexample appears.
- **Independent audit:** a no-import bracket-code generator matches every
  source edge list, recomputes determinants and cofactor adjugates, and closes
  all 136 targets after cyclic relabelling in 11,600,208 calls.  Its clique
  engine passes 1,500 brute-force tests, and five source corruptions fail
  closed.
- **Consequence:** every reduced rank-10 graph containing such a core has at
  most 62 vertices.  A certified order-62 graph contains a nonsingular
  unicyclic ten-core, so the class bound is sharp.  This closes the unicyclic
  route but not bicyclic or denser cores.  The exact milestone is frozen by
  `manifests/unicyclic_core_milestone.json`; it is a structural exclusion
  theorem, not a global counterexample or proof.

## RG10-O08: all connected bicyclic ten-vertex cores

- **Claim tested:** a 63-vertex reduced rank-10 graph has a nonsingular
  induced connected bicyclic principal core on ten vertices.
- **Complete domain:** 2,678 nonisomorphic graphs.  Generation from every
  unicyclic graph plus one nonedge and from every free tree plus two nonedges
  gives the same structural-code set: 345 dumbbells, 514 figure-eights and
  1,819 theta types.
- **Exact outcome:** 1,959 cores are singular.  For all 719 nonsingular
  cores, exact integer compatibility construction and 48,967,729 discovery
  branch nodes exclude a 53-profile noncore clique.  No counterexample
  appears.
- **Independent audit:** a separately written free-tree-plus-two-nonedges
  generator and bracket-word two-core canonicalizer matches every source
  isomorphism class, recomputes all Bareiss determinants and cofactor
  adjugates, and closes all 719 targets after cyclic relabelling in
  41,704,342 calls.  Its engine passes 1,500 cross-checks and five corrupted
  sources fail closed.
- **Consequence:** every reduced rank-10 graph containing such a core has at
  most 62 vertices.  A certified order-62 equality graph contains a
  nonsingular bicyclic ten-core, so the class bound is sharp.  This closes
  the bicyclic route but not connected ten-cores with twelve or more edges.
  See `proof/bicyclic_core_theorem.md` and
  `work/linear_extension/bicyclic_core_theorem_audit.md`.
