# Frozen source statement: win-00054-p04

For every finite simple connected graph `G` with at least two vertices, prove or disprove
\[
2b(G)-2\le \gamma_R(G),
\]
where `b(G)` is the graph burning number and `gamma_R(G)` is the Roman domination number. A disproof must give a graph with an exact graph6 (or edge-list) certificate and independently check both optimum parameters. A proof must use the standard simultaneous-spread burning convention and standard Roman dominating functions; any convention mismatch is outside scope.

Primary source: Jan Pastorek et al., *AutoGraphForge: Towards Automated Graph Theory Discovery*, arXiv:2609.03478v1, Sections 3.4 and 4.2. Machine-source locator: public repository `https://github.com/JanPastorek/AutoGraphForge`, commit `2bbf36e92328295976b1cd62b2a5e15f9a628e41`, `results/survivors_by_touch_normalised.txt`, entry `((nontrivial) and (connected)) => ((2 * burning_number)-2) <= roman_domination_number`, reported touch 2294. Survival of the dataset is evidence only, not a proof or an open-status guarantee.
