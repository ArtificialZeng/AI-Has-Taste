## 新WIN-1-07｜排列立方避免 \(2143\)：与“至多一个例外部件”的合成双射

- **精确定义**：令 \(b_n\) 为满足“\(\pi\) 避免 \(312,321\)，且 \(\pi^3\) 避免 \(2143\)”的 \(n\) 阶排列数。令 \(c_n\) 为 \(n\) 的有序正整数分拆数，其中除至多一个部件外，其余部件均属于 \(\{1,3\}\)；空分拆计一次。
- **待证命题**：对所有 \(n\ge0\)，\(b_n=c_n\)。等价的完整生成函数目标为
  \[
  \sum_{n\ge0}b_nz^n=
  \frac1{1-z-z^3}+
  \frac{z^2+z^4/(1-z)}{(1-z-z^3)^2}.
  \]
- **开放依据**：原文 §5 将立方情形单独列为猜测；其已证的平方模式分类没有解决此命题。[Archer–Bourne，§5](https://arxiv.org/html/2505.05218v3)。
- **AI 入口与验收**：本轮得到 \(b_0,\ldots,b_8=1,1,2,4,7,13,23,39,66\)。从合成编码追踪三次复合，尝试证明两个“例外部件”恰好触发禁形。首选产出可逆双射或等价结构定理。
