## Claim

For the labelled graph \(K_{3,3}\), with tubes, compatibility, maximal
tubings, flips, and the full-tube convention exactly as fixed in `source.md`
and `problem.md`, the flip graph has diameter exactly \(12\).

This is a finite computer-assisted proof candidate. It is not a referee
acceptance and makes no unconditional priority claim.

## Exhaustive state construction

The independent verifier specifies \(K_{3,3}\) by its nine individual edges
and computes induced connected components by graph traversal. It does not use
the specialized tube predicate or compatibility graph of the triage program.

For every connected induced vertex set \(S\), it recursively constructs all
graph search trees as follows: choose each possible root \(r\), compute all
connected components of \(G[S\setminus\{r\}]\), independently choose a search
tree on each component, and attach the chosen component roots to \(r\). This is
complete by induction on \(|S|\). Indeed, every search tree has a unique root,
and its child subtrees are precisely the search trees on those uniquely
determined components. The same observation shows that two recursion branches
cannot yield the same labelled parent vector.

The run constructs 552 parent vectors, 92 for each possible root. For every
vector, the verifier independently checks at every vertex \(v\) that its child
descendant sets are exactly the connected components obtained after deleting
\(v\) from its descendant set. It maps a tree to the sorted six descendant
sets, including the full set. These are 552 distinct maximal tubings. As a
cross-check performed only after this construction is complete, their exact
set equals all 552 tubings generated by the earlier Bron--Kerbosch
compatibility implementation. The canonical state-sequence SHA-256 is

`5621bdc6f16edfc5695d86b208dbc2ec6818d211e5c731fa498e06232b88d314`.

## Exhaustive legal-edge construction

Let \(s\) be the parent of \(t\) in a generated search tree. To rotate this
tree edge, the verifier promotes \(t\) above \(s\). An old child-subtree \(C\)
of \(t\) is reattached below \(s\) exactly when a vertex of \(C\) is adjacent
to \(s\) in \(G\); all other parent relations remain unchanged.

This rule follows directly from connected components. In the old descendant
set of \(s\), after deleting \(t\), the component containing \(s\) contains
exactly the old child-components of \(t\) that have an edge to \(s\), together
with the other old child-components of \(s\). A child-component of \(t\) with
no such edge is separated from all of these. Thus the rotated parent vector
satisfies the recursive search-tree definition. Its descendant-tube set
exchanges exactly one non-full tube.

The verifier applies this rule to each of the five tree edges of every state,
validates every rotated tree from first principles, checks that it lies in the
recursive census, and checks that every directed rotation has its inverse. It
obtains 2,760 directed rotations and 1,380 undirected edges, with degree five
at every state. As a second construction of legal edges, the earlier tubing
program deletes each possible non-full tube and joins the two maximal tubings
over every resulting ridge. The two complete edge sets are exactly equal. In
the common canonical state order their edge-list SHA-256 is

`1750eb6fc752dbd8495d2ce7706fefc117376dd98873df794ba6da7d8b1c431c`.

## Exact distances

On the independently rotated graph, the verifier runs ordinary unweighted BFS
from every one of the 552 states. Every run reaches all 552 states. Hence all
\(552^2=304{,}704\) ordered distances are covered. Their row-major byte-matrix
SHA-256 is

`19dfb29ade0634468ba84ad496356bef6342f3f553bd11d1384166a7461ddd93`.

For each source, the result file records the count and canonical-state hash of
every complete BFS layer, as well as a hash of the ordered distance row. Every
layer-count sequence sums to 552. The eccentricity histogram is

\[
  10:12,\qquad 11:108,\qquad 12:432.
\]

Therefore every distance is at most 12. For the reverse inequality, canonical
state 42, with tube masks

`[1, 9, 11, 15, 31, 63]`,

has BFS distance 12 from canonical state 551, with tube masks

`[32, 36, 52, 60, 62, 63]`.

The result file gives the complete explicit path of 12 direct rotations, with
state indices

`42, 6, 0, 1, 4, 5, 127, 130, 131, 263, 273, 275, 551`,

and records at each step the parent vector, all named tubes, and the promoted
parent--child pair. The BFS layer of the endpoint proves that no shorter path
exists. Thus the graph has both diameter at most 12 and a pair at distance 12,
which proves the claim subject to audit of the code and the standard finite
enumeration/BFS argument above.
