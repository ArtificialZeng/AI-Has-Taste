# Exact support audit for the 18 triangular rays

Run on 2026-09-08 with

```text
python3 evidence/verify_triangular_rays.py
```

The verifier represents each ordinary coefficient `P_alpha` by its exact
sparse dictionary in the twelve variables
`(a11,a12,a13,a21,...,a43)`.  It enumerates assignments of the four rows to
the three columns, multiplies sparse dictionaries over the nonnegative
integers, and performs exact coefficient and support comparisons.  There is
no floating-point arithmetic.

The coordinate order for `gamma` is

```text
004 013 022 031 040 103 112 121 130 202 211 220 301 310 400.
```

The verifier also checked that all 18 vectors are distinct, satisfy all three
balance equations, and have coordinate gcd one.  Coordinate gcd one makes
each vector primitive already in the ambient integer lattice and hence also
in the balanced sublattice.  Thus all 18 primitive triangular rays pass the
requested support-containment test; more strongly, the exact expansions give
`D_gamma-N_gamma` coefficientwise nonnegative on every ray.

This finite result does **not** settle the frozen universal statement.  The
real cone generated by the rays can have lattice points not generated by the
primitive rays as a monoid, and decompositions involving different coordinate
signs can cancel factors.
