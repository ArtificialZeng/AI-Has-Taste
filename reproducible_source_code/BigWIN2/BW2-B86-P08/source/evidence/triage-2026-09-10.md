## Cheapest discriminating mathematical test

Orient the boundary sphere by outward normals. At a vertex `v`, choose the
cyclic neighbors `u_0,...,u_(d-1)` so that every incident face has positive
boundary `(v,u_i,u_(i+1))` (indices modulo `d`). Put

```
r_i = |v u_i|,       q_i = |u_i u_(i+1)|.
```

Every face is direct, so `(r_i,q_i,r_(i+1))` is a cyclic rotation of
`(a,b,c)`. If `psi=(a b c)`, this forces

```
q_i = psi(r_i),       r_(i+1) = psi^2(r_i).
```

Thus closure forces `(psi^2)^d(r_0)=r_0`, equivalently `3 | d`. In
particular there is no legal degree-four or degree-five oriented star. The
script `evidence/check_oriented_stars.py` independently enumerates the finite
label constraints for degrees 3 through 12.

For `d=3`,

```
q_(i+1) = psi(r_(i+1)) = psi^3(r_i) = r_i,
```

so every radial edge is equal to its opposite edge in the tetrahedron on
`v,u_0,u_1,u_2`.

For a triangulated sphere, `3F=2E` and Euler's formula give

```
sum_v (6-deg(v)) = 12.
```

All vertex degrees are at least three. If all are divisible by three and none
is three, all are at least six, contradicting the displayed identity. Hence a
degree-three vertex exists. At such a vertex the tangent cone is
full-dimensional and its three extreme rays are exactly the three incident
edge rays, so those rays are linearly independent. The four vertices therefore
form a nondegenerate tetrahedron. The three actual incident triangular facets
and the opposite triangle all have side multiset `{a,b,c}` by the opposite-edge
equalities. Georgiou's Lemma 5 would then force `T` acute, contrary to
`c^2 >= a^2+b^2`.

This is strong triage evidence for the proposed route, not a referee acceptance
or a released mathematical result. The next phase must audit the surface
orientation convention, the tangent-cone assertion, and the use of Lemma 5 in
a self-contained proof.
