# Immutable source: win-00061-p02

## Frozen problem

Use the definitions in arXiv:2609.01889v1. For every finite simple graph `G` on at most six vertices, determine whether `G` is Hall-universal: for every simple graph `H` on the same labelled vertex set, the Hilton–Johnson Hall condition for the graphic lists `L(v)=N_G(v)` implies that `H` admits a proper `L`-coloring.

Produce a complete census up to graph isomorphism. For every non-Hall-universal class, give an explicit witness `H`, an exact verification of Hall's condition on every required connected induced subgraph, and a complete certificate that no proper graphic-list coloring exists. For every Hall-universal class, give a reproducible exhaustive certificate covering every `H`. State which positive classes are already immediate from the source's known families and isolate any first class not so covered. Finite numerical counts without witnesses/hashes do not answer the problem.
