# Order-nine line-graph signature submission package

The manuscript source is `paper/main.tex`; its bibliography is
`paper/references.bib`. Run `latexmk -pdf main.tex` from the `paper`
directory to build the article.

`REPRODUCE.md` records the exact census commands. The archive also contains
the complete connected order-nine graph6 input, the primary rational
congruence census, the independent FLINT characteristic-polynomial/Sturm
verifier, the direct line-graph equality checker, exact outputs, logs, and
the proof/citation/PDF audits. `MANIFEST.json` records the package members.

The corresponding submission PDF is distributed separately as
`order9_linegraph_signature.pdf`.
