# Bounded primary-literature check for the five-vertex fork

Checked on 2026-09-10 (Asia/Shanghai) for research job
`win-00086-p07-research-6249c24c714d`.

The current arXiv record for Yair Caro, Zsolt Tuza, and Christina Zarb,
*Induced/Incomparable versus Ramsey*, arXiv:2605.22077, was inspected at
<https://arxiv.org/abs/2605.22077>.  It identifies v2, revised 2026-05-27, as
the latest version.  Its abstract gives the general tree bounds and poses the
determination of `f(H)`; the source PDF locations and the application to the
five-vertex tree are recorded precisely in `problem.md`.

Primary-source searches were run for the exact title and arXiv identifier and
for combinations/equivalent terminology involving `H-exact`, `Exact(H)`,
`f(H)`, `f(T)`, `subdivided claw`, and the standard five-vertex name `fork`,
both generally and restricted to arXiv.  The searches returned the source
preprint, mirrors/reviews of it, and unrelated papers using “fork” or
“subdivided claw” in other graph-theoretic settings.  No later primary paper
or later arXiv version resolving `f(T*)` for the five-vertex fork was located.

This is a bounded search result, not proof of priority or exhaustive coverage.
The precise defensible comparison is: relative to arXiv:2605.22077v2, which
gives `8 <= f(T*) <= 16`, the certificate in this project supplies the missing
nine-vertex nonexistence result and hence the exact value eight.  Any release
review should repeat the search.
