# win-00065-p04 — Maxwell sharpness for pure `C3/C4` complement components

For all integers `s,t>=0` with `n=3s+4t>=4`, let
`F=sC_3 disjoint-union tC_4` and `G=overline F`. Using exactly the generic-rigidity and Maxwell-dimension conventions of Guler–Jackson, prove or disprove

> `rig(G)=M(G)`.

This is the pure exceptional-component family omitted by Theorem 1.4, not a claim about all complements of maximum degree two. Begin with exact adversarial rank tests for small `(s,t)`. A counterexample requires its exact Maxwell dimension and a rigorous generic-rank obstruction; a positive theorem needs a uniform rigidity-matroid/join argument rather than random-coordinate rank alone.
