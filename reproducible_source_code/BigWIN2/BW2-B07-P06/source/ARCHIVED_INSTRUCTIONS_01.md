# Source and ancillary files

Run `latexmk -pdf main.tex` to build the manuscript. The required LaTeX
packages are standard TeX Live packages; the bibliography uses BibTeX.

The `ancillary/` directory in the release archive contains the exact Python
programs, fixed finite-result files, proof notes, formal/source statements,
and reproduction instructions described in the manuscript. See
`ancillary/experiments/README.md` for commands and trust boundaries.
