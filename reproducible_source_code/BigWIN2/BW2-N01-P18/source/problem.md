## Precise statement

For every prime integer p, put K=F_p and P(x)=x^(p-1)+x^(-1) in
K[x,x^(-1)]. For every Laurent polynomial
Q(x)=sum_{r in Z} q_r x^r with q_r in K and only finitely many nonzero q_r,
define u(Q)=(u_n)_{n>=0} by

    u_n = [x^0](P(x)^n Q(x)) in K.

Here [x^0] extracts the coefficient of x^0, and P^0=1. In particular,
u_0=[x^0]Q is part of the sequence. Zero Q and p=2 are included.

A word u is recurrent exactly when

    for every i>=0, length l>=1, and cutoff N>=0,
    there is an integer j>N such that
    u_(j+k)=u_(i+k) for every integer 0<=k<l.

Thus every occurring finite contiguous block must occur arbitrarily far out.
No bounded-gap, uniform-recurrence, density, or linear-recursion requirement
is imposed. The source is unambiguous on this distinction.

The original candidate is

    for every prime p and every Q in F_p[x,x^(-1)],
    u(Q) is recurrent iff u_n=0 for all n>=0.

If false, the requested fallback is a nonzero recurrent counterexample and
explicit algebraic conditions describing **all** recurrent Q for the given
family of primes and P. An isolated counterexample does not finish that
classification request. A finite zero prefix does not prove the all-n condition.

For monomials, direct expansion gives the exact formula

    [x^0]P^n x^r = binom(n,(n-r)/p) mod p,

interpreted as zero unless (n-r)/p is an integer in [0,n]. This covers
negative r as well. Formal residue arguments below initially use only r>=0.
