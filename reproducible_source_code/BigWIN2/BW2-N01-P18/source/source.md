## 新WIN-1-18｜退化常数项序列：复现是否只能发生在恒零情形？

- **精确定义**：取素数 \(p\)，固定 \(P(x)=x^{p-1}+x^{-1}\)。对任意 \(Q(x)\in\mathbb F_p[x,x^{-1}]\)，令 \(u_n=[x^0]P(x)^nQ(x)\)。称序列复现，若每个出现过的有限连续片段都在任意远处再次出现。
- **本批候选命题**：\((u_n)_{n\ge0}\) 复现，当且仅当它恒为零。若该命题失败，则以反例为起点，给出使序列复现的全部 \(Q\) 的显式代数条件。
- **开放依据**：原文 Question 20 专门留下 \([x^0]P^n=0\) 对所有 \(n>0\) 成立时的复现问题，并列出这个 \(P\)。上述“当且仅当”是本批提出的明确候选，不冒充作者原猜测。[Kohen，Question 20](https://cs.uwaterloo.ca/journals/JIS/VOL29/Kohen/kohen9.pdf)。
- **AI 入口与验收**：先对单项式 \(Q=x^r\) 用 Lucas 同余分析，再研究有限线性组合的抵消。非零复现反例须附自动机证明；非复现证书可是一段出现过却此后不再出现的词及其严格排除理由。这里的复现不要求有界间隔。
