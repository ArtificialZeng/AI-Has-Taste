All operations are exact bit/set operations.  A state is represented by the
two uniform background bits and the finite sets on which its two components
differ from that background.  At one update, every possible new defect lies
either at an old memory defect or within radius one of an old current defect;
the script evaluates exactly that exhaustive candidate set.  Equality of the
background bits and both defect sets is equality of the configurations on all
of Z.  The reported first positive recurrence is therefore the least period
within each completed search, not merely a return time.
