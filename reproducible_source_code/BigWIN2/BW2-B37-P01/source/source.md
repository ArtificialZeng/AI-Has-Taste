# Even-parameter period formula for RESOCA rule 115

Use exactly the definitions, global update rule, least-period convention, and
finite initial-configuration family denoted `1(01)^k` in Section 6 of
Formenti--Kamilya, arXiv:2606.13159 / DOI 10.4204/EPTCS.445.12.

Prove or disprove their Conjecture 3:

\[
P(2i)=\frac{2\,4^{2i+2}-7\,4^{i+1}+5}{3}
\quad\text{for every integer }i\geq0.
\]

An exact counterexample must establish the *least* period, not only exhibit a
return time.  If source conventions exclude one or more small indices, preserve
the displayed original quantifier and state any corrected formulation
separately rather than silently changing it.
