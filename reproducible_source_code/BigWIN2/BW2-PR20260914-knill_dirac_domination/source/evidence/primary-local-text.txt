The connection Laplacian L L and the Dirac matrix D D are both n × n n\times n matrices defined from a given finite abstract simplicial complex G G with n n sets. In both cases, there is interlacing of the eigenvalues for subcomplexes. This gives general upper bounds of the eigenvalues λ j ≤ d j \lambda_{j}\leq d_{j} both for L L and D D in terms of inclusion or intersection degrees. We conjecture that L L always dominates both D D and g = L − 1 g=L^{-1} in a weak Loewner sense. In a second part we look at dynamical systems ( G , T ) (G,T) , where T T is a simplicial map on G G . Both L L and D D generalize to dynamical versions L T L_{T} and D T D_{T} . L T L_{T} is still unimodular with an explicit Green function inverse g T g_{T} and D T = d T + d T ∗ D_{T}=d_{T}+d_{T}^{*} still comes from an exterior derivative d T d_{T} . We also review the Lefschetz fixed point theorem ∑ x ∈ F i T ​ ( x ) = χ T ​ ( G ) \sum_{x\in{\rm F}}i_{T}(x)=\chi_{T}(G) for a simplicial map T T on a finite abstract simplicial complex G G . It implies the Brouwer fixed point theorem telling that simplicial map on a contractible finite abstract simplicial complex G G always has at least one simplex fixed. This is all combinatorial as no geometric realizations are ever involved. 1. Introduction 1.1. If G G is a finite abstract simplicial complex with n n sets, both the Dirac matrix D D as well as the connection matrix L L are n × n n\times n matrices. The Dirac matrix D = d + d ∗ D=d+d^{*} uses the exterior derivative d d is a matrix d ⁡ ( x , y ) = sign ⁡ ( x , y ) d(x,y)={\rm sign}(x,y) if | x | |x| and | y | |y| differ by 1 1 and y ⊂ x y\subset x and d ⁡ ( x , y ) = 0 d(x,y)=0 else. The connection matrix is defined as L ⁡ ( x , y ) = 1 L(x,y)=1 if x ∩ y ≠ ∅ x\cap y\neq\emptyset and L ⁡ ( x , y ) = 0 L(x,y)=0 else. Its inverse g = L − 1 g=L^{-1} defines Green functions g ⁡ ( x , y ) g(x,y) . Both the Hodge Laplacian H = D 2 = d ​ d ∗ + d ∗ ​ d H=D^{2}=dd^{*}+d^{*}d and the connection Laplacian L 2 L^{2} have non-negative spectrum.
