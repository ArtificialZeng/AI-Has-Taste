# Precise problem reading

## Frozen target

Let

\[
Q=\begin{pmatrix}
1/4&-1/2&0&0\\
-1/2&1&-1&0\\
0&-1&1&-1/2\\
0&0&-1/2&1/4
\end{pmatrix},\qquad
c=(1/2,1,0,0)^\top .
\]

These are exactly equation (5) of Zhang--Wang, arXiv:2609.03617v1,
at `n=4` and `a=b=1/2`.  Write \(\langle Q,X\rangle=\operatorname{tr}(QX)\)
for the Frobenius product and

\[
L(x,X)=\langle Q,X\rangle+c^\top x
=\tfrac14X_{11}+X_{22}+X_{33}+\tfrac14X_{44}
-X_{12}-2X_{23}-X_{34}+\tfrac12x_1+x_2.
\]

Index a probability vector by binary strings rather than by the paper's
unspecified ordering of the vertices: let

\[
\Delta=\{p=(p_z)_{z\in\{0,1\}^4}:p_z\geq0,\ \sum_zp_z=1\}.
\]

The precise reading of relaxation (9) is the finite conic program

\[
v_*=\min L(x,X)
\]

over \(x\in\mathbb R^4\), \(X\in\mathbb S^4\), and \(p\in\Delta\), subject to

\[
Y(x,X):=\begin{pmatrix}1&x^\top\\x&X\end{pmatrix}\succeq0,
\quad x_i=\sum_zp_zz_i\ (i=1,\ldots,4),
\quad X_{ij}=\sum_zp_zz_iz_j\ (1\leq i<j\leq4).
\]

Thus the full off-diagonal projection \((x,(X_{ij})_{i<j})\) is in the
Boolean quadric polytope \(\mathcal B_4\).  In particular, this is not a
reading with only the displayed McCormick inequalities.  The diagonal entries
\(X_{ii}\) are **not** constrained to equal \(x_i\); they are constrained only
through \(Y\succeq0\).  The convex-combination equations imply
\(0\leq x_i\leq1\), so no separate box constraints are added.

Determine all of the following:

1. the exact real number \(v_*\);
2. the complete exposed optimal face
   \[
   \mathcal F_*:=\{(x,X,p): (x,X,p)\text{ satisfies the constraints above and }
   L(x,X)=v_*\};
   \]
3. an exact feasible primal point in \(\mathcal F_*\) and an exact feasible
   dual solution of this same finite conic formulation with equal objective
   values, including exact PSD/nonnegativity verification.

The requested face includes the auxiliary distribution \(p\).  If it is more
compact to state first the projected face in \((x,X)\), the full set of all
representing \(p\)'s must still be specified.  Decimal solver output, an
unproved algebraic reconstruction, or only the known value `-1/100` does not
meet the target.

## Manifest symmetry and quotient convention

Let \(R\) reverse four coordinates and \({\bf1}\) be the all-one vector.  The
reverse-complement involution is

\[
x'={\bf1}-Rx,
\quad X'={\bf1}{\bf1}^\top-{\bf1}(Rx)^\top-(Rx){\bf1}^\top+RXR^\top,
\quad p'_u=p_{{\bf1}-Ru}.
\]

It preserves every constraint and the objective because
\(RQR=Q\), \(-2RQ{\bf1}-Rc=c\), and
\({\bf1}^\top Q{\bf1}+c^\top{\bf1}=0\).  “Up to the manifest symmetries” means
classification modulo the order-two group generated by this involution; mere
reordering of the sixteen vertex labels is only notation.  Symmetrization
shows that a fixed optimal point exists, but does not by itself classify all
optimal points.

## Prior-result and status check

The primary source was inspected on 2026-09-07 at
<https://arxiv.org/html/2609.03617v1>.  Proposition 1 proves that the underlying
box-constrained quadratic program has optimum `0`.  Proposition 2 gives the
weaker McCormick relaxation the exact value
\(\sqrt3-7/4\).  Equation (9), Proposition 3, and Appendix A provide only a
feasible point for the full-BQP relaxation with value \(-1/100\), while the
text reports an uncertified numerical optimum near \(-0.0108\).  Consequently
the source rigorously gives

\[
\sqrt3-\tfrac74\ \leq v_*\leq-\tfrac1{100},
\]

but does not give the exact value, the full optimal face, or a matching dual
certificate for (9).  Exact-assertion searches on 2026-09-07 for the arXiv ID,
the value `0.0108`, and the rational certificate located the source and mirrors
only; this is a limited search result, not a priority or open-status proof.
The source status is therefore `new-question` / `status-uncertain`, and the
nearest prior result is arXiv:2609.03617v1 itself.
