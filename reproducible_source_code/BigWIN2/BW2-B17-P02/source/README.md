# Reproducing the exact value f_3(126)=16

Fast exact checks:

```bash
python3 code/verify_witness.py certificates/witness_126_16.json --n 126 --size 16
python3 code/crosscheck_small.py
```

Regenerate the decisive CNF byte-for-byte:

```bash
python3 code/generate_cnf.py --n 126 --k 17 \
  --output certificates/f3_126_ge17.cnf \
  --meta certificates/f3_126_ge17.meta.json
```

Full proof replay (about eight minutes on the recorded machine):

```bash
tools/drat-trim-bin/usr/bin/drat-trim \
  certificates/f3_126_ge17.cnf certificates/f3_126_ge17.drat
```

The successful run must end with `s VERIFIED`. Python 3.10 and python-sat
1.8.dev24 were used; the proof was generated by CaDiCaL 1.9.5 and checked with
Debian's `drat-trim` package version `0.0~git20240428.effa1dc-2`.
