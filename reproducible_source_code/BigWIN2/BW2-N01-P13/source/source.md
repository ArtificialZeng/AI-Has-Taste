## 新WIN-1-13｜有限域 \(q\)-命中数的二次低阶系数是否非负？

- **精确定义**：对棋盘 \(B\subseteq[n]^2\)，令 \(m_i(B,q)\) 为支撑包含于 \(B\) 的秩 \(i\) 矩阵数，\(M_i=m_i/(q-1)^i\)。用
  \[
  \sum_{d=0}^{n}H_d(B,q)t^d
  =q^{\binom n2}\sum_{i=0}^{n}M_i(B,q)[n-i]!_q
  \prod_{j=0}^{i-1}(tq^{-j}-1)
  \]
  定义 \(H_d\)，其中 \([r]!_q=\prod_{j=1}^{r}(1+\cdots+q^{j-1})\)。
- **待证命题**：令 \(x=q-1\)。已知存在唯一整数系数多项式 \(c_0+c_1x+c_2x^2\)，使 \(H_d(B,x+1)\equiv c_0+c_1x+c_2x^2\pmod{x^3}\) 对所有素数幂 \(q=x+1\) 成立。证明任意 \(B,d\) 均满足 \(c_2\ge0\)。
- **开放依据**：原文证明一次系数非负，并证明低阶模多项式展开存在；一般非负性仍为 Conjecture 4.1。本题只攻二次系数。[Chen–Selover，Conjecture 4.1、Theorem 4.10](https://ecajournal.haifa.ac.il/Volume2026/ECA2026_S2A22.pdf)。
- **AI 入口与验收**：扩展原文的对角群轨道分类，抽取二次贡献，寻找非负组合表达；或给出一个棋盘及严格算出的负 \(c_2\)。不能假设所有棋盘的 \(H_d\) 本身都是多项式。
