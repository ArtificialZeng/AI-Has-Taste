## Immutable problem statement

For integers `m>=2` and `l>=1`, let `H_m` be obtained from the complete graph on vertices `a,b_1,...,b_m` by subdividing every edge `ab_i` once, with new vertex `x_i`. Let `J_{m,l}=K_l vee H_m` be the complete join.

Prove that `J_{m,l}` is resistance-positive (and hence resistance-nonnegative) for every `m<=2l+3`, or disprove this assertion with an exact parameter pair and a valid obstruction certificate. Together with source Proposition 16, a proof would give the exact threshold `J_{m,l} is RP iff m<=2l+3`.
