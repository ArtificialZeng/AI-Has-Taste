## Frozen problem

Consider generic dense polynomial dynamical systems with two state variables (`n=2`), one differential parameter (`m=1`), degree data

- `[D_x,D_u,D]=[1,1,1]`, and
- `[d_x,d_u,d]=[1,0,1]`,

under the definitions and normalization of arXiv:2609.03828v1. The first corresponding line of the differential-parameter experiment in §4.2 reports seven candidate support monomials from Theorem 3.7 but only six stable actual monomials. Determine the generic eliminant symbolically, identify the missing monomial, and prove an exact additional support equality or inequality explaining `7 -> 6`. The proof must use independent coefficient indeterminates or an equivalent Zariski-open argument; agreement for finitely many finite-field samples is not a generic proof.
