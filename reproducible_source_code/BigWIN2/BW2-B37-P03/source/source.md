# Rational 18-variable Chebyshev seventh-moment system

Decide whether there exist rational numbers `x_1,...,x_18` satisfying all three
equations

\[
\sum_{j=1}^{18}x_j^2=9,\qquad
\sum_{j=1}^{18}x_j^4=\frac{27}{4},\qquad
\sum_{j=1}^{18}x_j^6=\frac{45}{8}.
\]

Either give an exact rational solution or prove none exists.  The initial claim
does not impose distinctness, nonzero coordinates, or `|x_j|<1`; do not add
those restrictions.  If the unrestricted system is soluble, any stronger
Chebyshev-design statement must be clearly separated.

Nearest result: user bibliography row 38 proves nonexistence for the analogous
17-variable system, even without distinctness and interval restrictions.
