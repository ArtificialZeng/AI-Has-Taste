# Primary-source and literature check

Date checked: 2026-09-09.

The official HTML for Nicolussi Golo--Pinamonti--Warhurst,
*Harmonic morphisms of sub-Riemannian Lie groups*, arXiv:2609.04299v1,
was inspected at <https://arxiv.org/html/2609.04299v1>.

- Section 4.3 defines a polarization as a bracket-generating linear subspace,
  meaning one that Lie-generates the Lie algebra.
- Definition 8.2, equations (57)--(60), defines the two projected trace
  characters with \(\operatorname{ad}_B(X)=[B,X]\) and says that modular
  balance is exactly their simultaneous vanishing on the complementary
  summands.
- Lemma 10.6, equations (92)--(96), uses the graph complement
  \(\mathfrak q_\Psi=\{Z-\Psi Z:Z\in\mathfrak q\}\) and verifies the
  transformed vertical trace character.
- Section 10.2, Question 1, asks whether a polarized Lie algebra can admit a
  complement with \(\kappa_{\mathfrak q}|_V=0\) but no modularly balanced
  complement.

Exact-phrase web searches for the text of Question 1, "modularly balanced
complement", and "modular mismatch" together with polarized Lie algebras
found no separately indexed primary source resolving this question. The only
directly relevant primary item found was arXiv:2609.04299v1 itself. This is a
small, date-bounded screen and is not evidence of priority or an exhaustive
literature review.
