## Why the finite calculation proves the statement

### Complete input domain

`enumerate_borel15.py` constructs the input domain in two ways.  Its first
generator adds outer corners to exhaust all coordinate downsets of size 15,
then imposes the standard-set Borel moves.  Its second generator recursively
unites the one-point closures under coordinate predecessors and Borel right
shifts.  Deletion of a maximal point proves completeness of the first
recursion; every closed set being the union of the closures of its points
proves completeness of the second.  The degree-
\(<15\) bound follows because a point of degree (d) forces a chain of
(d+1) standard monomials.  Both algorithms give the identical canonical set
of 107 ideals, not just the same count.  Full details and the deterministic
atlas digest are in `borel15-census.md`.

### Exact Hom matrix

Let (g_1,\ldots,g_s) be the minimal generators and let (A=R/I).  In the
surjection \(\bigoplus_i Re_i\to I\), the kernel is generated by the Taylor
relations

\[
\frac{\operatorname{lcm}(g_i,g_j)}{g_i}e_i-
\frac{\operatorname{lcm}(g_i,g_j)}{g_j}e_j \qquad(i<j).
\]

Consequently an arbitrary tuple of images \((a_1,\ldots,a_s)\in A^s\)
defines a member of \(\operatorname{Hom}_R(I,A)\) exactly when every displayed
relation vanishes after (e_i\mapsto a_i).  Expanding each (a_i) in the 15
standard monomials gives an integer matrix: multiplication by a monomial
sends a standard monomial either to one standard monomial or to zero.  Its
nullity over \(\mathbb Q\) equals its nullity over \(\mathbb C\).

`tangent_borel15.py` builds all pairwise Taylor relations for every atlas
record and uses exact `SparseMatrix.rank` on the integer matrix.  There are no
floating-point ranks or probabilistic primes.  The resulting 107-record table
is `borel-tangents-15.jsonl`; it contains the matrix dimensions, exact rank,
and nullity for every ideal.  Its SHA-256 is

```
28aa1f612554335a53f56a0d86d820cadcbfec903e227e7136b17d0e2e046951
```

Taking the maximum of this complete table gives the value and equality list
above.

### Independent syzygy calculation

Every atlas ideal is strongly stable, so its first syzygy module also has the
Eliahou--Kervaire presentation.  For every minimal generator (g) and every
(i<\max(g)), write the unique stable factorization

\[
x_i g=g(x_i g)c,\qquad \max(g(x_i g))\le\min(c),
\]

and use the relation (x_i e_g-c e_{g(x_i g)}).  In the induced coefficient
system over the standard monomial basis, each nonzero equation is either
one variable equal to zero or two variables equal to one another.  Its
nullity is therefore exactly the number of connected components not pinned
to zero.

The primary script implements this presentation and component count
separately and obtains the Taylor nullity on all 107 records.  In addition,
`verify_tangent_extrema.py` imports no primary implementation code and repeats
the stable factorization, EK relations, and component calculation from
scratch for the four dimension-81 ideals and the unique dimension-69
competitor.  `tangent-extrema-independent.json` records dimensions
\(81,81,81,81,69\) and exact equation counts.  Thus all decisive equality and
strict-comparison cases have a standalone second replay.
