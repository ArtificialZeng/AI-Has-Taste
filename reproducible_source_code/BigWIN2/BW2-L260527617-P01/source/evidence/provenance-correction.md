# Provenance correction for the twelve finite lower-bound certificates

Project: `lit-260527617-p01`

This is new evidence for a formal mathematical revision. It corrects a false
solver attribution in the accepted snapshot and specifies the independent
replay that the revised claim package must record.

## What generated the archived artifacts

The twelve archived pairs `evidence/L*.cnf` and `evidence/L*.drup`, covering
all positive-even multiplicity partitions of lengths 10, 12, 14, 16, and 18,
were generated by `evidence/search_exact_sat.py` under Python 3.10.12 with
PySAT 1.8.dev24 and solver name `glucose3`. The research job event record

`jobs/lit-260527617-p01-research-da12467f28f9/events.jsonl`

contains the exact invocations and outputs. In particular, completed command
items 45--56 invoke the generator with `--solver glucose3`, `--cnf`, and
`--proof`; each output records `solver = glucose3`, `result = unsat`, and a
positive `proof_lines` count. Those commands created:

`L10_22222`, `L12_22224`, `L14_22226`, `L14_22244`, `L16_22228`,
`L16_22246`, `L16_22444`, `L18_222210`, `L18_22248`, `L18_22266`,
`L18_22446`, and `L18_24444`.

Therefore the sentence in the current manuscript that says CaDiCaL 1.9.5
"emitted" the twelve textual DRUP derivations is false. The docstring of
`evidence/check_drup.py` makes the same false attribution and must also be
corrected. This correction does not alter the mathematical scope or the
finite family of instances.

## Role of CaDiCaL

PySAT/CaDiCaL 1.9.5 was used in separate SAT-status cross-checks, including
length-18 multiplicity cases; it did not generate the twelve archived DRUP
files. A later release-context run separately cross-checked the
`L=18, (2,4,4,4,4)` instance. These checks may be reported as corroboration,
but not as the provenance of the archived proofs.

## Required revision test

The final evidence must independently run `drat-trim` on every one of the
twelve archived CNF/DRUP pairs, retain a machine-readable result or complete
replay log binding each result to both SHA-256 digests, and require exit code
zero plus the exact success marker `s VERIFIED` for every pair. The revised
manuscript must state that Glucose3 produced the archived DRUP traces and that
`drat-trim` independently verified them. The custom checker may remain a
second replay path, but it is not a substitute for the recorded `drat-trim`
audit.

No novelty, priority, or stronger mathematical claim follows from this
provenance correction.
