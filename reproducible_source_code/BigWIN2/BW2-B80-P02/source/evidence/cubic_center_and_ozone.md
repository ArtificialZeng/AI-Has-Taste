# Exact cubic center and ozone calculation

This dossier concerns exactly the algebra in `source.md`.  Write
`x=e1`, `y=e2`, and put `t=e3=xy-q^2 yx` and
`z=yt-q^2ty`.  Throughout, `q^3=1`, `q!=1`, so
`q^2+q+1=0`, `q^{-2}=q`, and both `q^2-1` and `q^4-1=q-1`
are nonzero.

## 1. PBW/Ore presentation at order three

Consider the iterated Ore extension

```
R = k[z,t][x;sigma_1][y;sigma_2,delta_2]
```

whose defining commutations, in PBW order `z<t<x<y`, are

```
z central,     xt=q tx,     yt=q^2 ty+z,     yx=q xy-q t.       (1)
```

Here `sigma_1(t)=qt`, `sigma_1(z)=z`, while
`sigma_2(t)=q^2t`, `sigma_2(x)=qx`, `sigma_2(z)=z` and
`delta_2(t)=z`, `delta_2(x)=-qt`, `delta_2(z)=0`.  The only
compatibility needing a check is the relation `xt=qtx`; applying
`delta_2` to its two sides gives `qxz-qt^2` in both cases.  Thus the
extension exists, has basis

```
{ z^d t^c x^a y^b : a,b,c,d >= 0 },                           (2)
```

and is a domain.

This is not an assumed generic presentation.  It is directly isomorphic to
the cubic specialization of `source.md`.  Relations (1) give
`xy-q^2yx=t` and `yt-q^2ty=z`.  The relation `xt=qtx` is equivalent,
after substituting for `t`, to

```
x^2y+xyx+yx^2=0.
```

Moreover, direct expansion gives

```
yz-zy = q^2(xy^3-y^3x),                                      (3)
```

so centrality of `z` gives the second specialized Serre relation.  Conversely,
inside the algebra of `source.md`, the first Serre relation gives `xt=qtx`;
the definitions give the last two relations in (1); equation (3) and the
second Serre relation give `[y,z]=0`; and a reduction using `xt=qtx` gives
`xz=zx`.  Then `z` also commutes with `t`.  The maps in the two directions fix
`x,y` and recover the displayed `t,z`, hence are inverse.  This proves (1),
(2), and the domain assertion at the excluded parameter without specialization
of an `m>=5` theorem.

## 2. Central elements

The specialized Serre relations immediately give `x^3,y^3` central: multiply
the first relation on the left and right by `x` and subtract, while the second
is `[y^3,x]=0`.  From (1),

```
y t^n = q^(2n)t^n y + (1+q^2+...+q^(2(n-1))) z t^(n-1).
```

Consequently `t^3` is central; `z` is central by Section 1.  Finally set

```
s = xyt + xz/(q^2-1) + t^2/(q^4-1).                           (4)
```

The denominators are nonzero.  For a transparent direct check, put
`alpha=1/(q^2-1)`, `beta=1/(q-1)`, and
`gamma=1+alpha=-beta`.  In PBW order, (4) is
`s=txy+gamma*zx+beta*t^2`.  Relations (1) give `[s,t]=[s,x]=0` from

```
alpha = -1+alpha*q^2,        beta = -1+beta*q,
```

and `[s,y]=0` from

```
gamma=1+gamma*q,   beta=-1+beta*q,   gamma+beta=0.
```

It also commutes with `z`.  Hence all five displayed elements are central.
The exact reductions are independently executable in
`evidence/verify_cubic_rewrites.py`.

## 3. No other center generators

Filter `R` by total exponent in the four PBW generators in (2).  The correction
terms `z` in `yt` and `t` in `yx` have smaller filtered degree.  Therefore the
associated graded algebra is the quantum affine space with `z` central and

```
xt=qtx,       yt=q^2ty,       yx=qxy.                          (5)
```

For its PBW monomial `t^c x^a y^b z^d`, commutation with `t,x,y` shows that it
is central exactly when

```
a+2b = 0,   b-c = 0,   a-c = 0       (mod 3),
```

equivalently `a=b=c (mod 3)`; `d` is arbitrary.  PBW independence also shows
that every central polynomial is a linear combination of just these central
monomials.  The nonnegative exponent semigroup is generated by

```
(3,0,0,0), (0,3,0,0), (0,0,3,0), (0,0,0,1), (1,1,1,0),       (6)
```

where the first three coordinates are `a,b,c`.  Indeed subtract the common
residue `r in {0,1,2}` and divide the first three coordinates by three.

If `C` is central in `R`, its top filtered symbol is central in (5).  By
(6), that symbol is a polynomial in the top symbols of
`x^3,y^3,t^3,z,s`; the last one is the nonzero monomial `txy`.  Subtract the
same polynomial in the five central lifts.  This strictly lowers filtered
degree and preserves centrality.  Induction, starting with the scalars, proves

```
Z(R) = k[x^3,y^3,t^3,z,s].                                    (7)
```

This argument audits the cubic semigroup and the complete leading-term lift;
it uses no localization and no theorem restricted to `m>=5`.

## 4. Ozone group

Use now the original connected grading
`deg(x)=deg(y)=1`, `deg(t)=2`, `deg(z)=3`, for which (1) is homogeneous.
By the PBW domain result, the top degree of a product of nonzero elements is
the sum of their top degrees.

Let `phi` fix the center pointwise.  Since `phi(x)^3=x^3`, degree comparison
gives `deg(phi(x))=1`.  Its constant term is zero by comparing degree-zero
parts, so `phi(x)=a x+b y`.  The quotient by the two-sided ideal `(x)` is
`k[y]`; reducing the cube equality there gives `b=0`, then `a^3=1`.
Similarly, using `R/(y)=k[x]`,

```
phi(x)=a x,       phi(y)=b y,       a^3=b^3=1.                (8)
```

Definitions give `phi(t)=ab t` and `phi(z)=ab^2 z`.  Pointwise fixation of
the nonzero central PBW generator `z` yields `ab^2=1`.  Every term of (4)
scales by `a^2b^2`; fixation of the nonzero element `s` yields
`a^2b^2=1`.  Hence `a=1`, then `b^2=b^3=1`, so `b=1`.  Thus every
center-fixing automorphism is the identity, and the identity plainly fixes
(7) pointwise:

```
Oz(A) = {id_A}.
```
