## 新WIN-1-05｜aba 避免栈：长度 \(2k+2\) 的最难集合划分

- **精确定义**：用字母词表示集合划分，同字母表示同一块，整体重命名视为等价。定义贪心栈映射 \(\phi\)：压入下一字母若会使栈出现子序列 \(aba\)，其中 \(a\ne b\)，则先弹栈；否则压入。每种字母的全部出现连成一段时称为已排序。
- **精确问题**：对所有 \(k\ge3\)，分类并计数所有恰有 \(k\) 种字母、长度 \(2k+2\)、经过 \(\phi^{k-1}\) 仍未排序的词，记等价类数为 \(M_k\)。求统一结构描述及 \(M_k\) 的闭式或递推。
- **开放依据**：已有结果给出最短长度 \(2k\) 及长度 \(2k+1\) 的完整计数；一般最难对象分类仍开放，本题推进尚未覆盖的下一整层。[Choi–Gan–Li–Zhu，Theorems 1.1–1.2](https://ecajournal.haifa.ac.il/Volume2025/ECA2025_S2A1.pdf)。
- **AI 入口与验收**：按首次出现顺序规范化字母，并利用原文关于连续字母块的引理剪枝。重点研究额外两次出现的分配。完整成果须覆盖所有 \(k\)，而非只拟合少量 \(M_k\)。
