# CC-P07 — There are no nine poison cards in Late Binding solitaire

[Final PDF / 最终稿](../../../pdfs/ClaudeCode/CC-P07_No_nine_poison_cards_in_Late_Binding_solitaire.pdf) · [LaTeX entry / 入口](source/manuscript/main.tex) · [Evidence / 复现材料](source/evidence/)

Collection / 合集: Claude Code. First obtained / 首次得到: 2026-11-18. Archived / 入库: 2026-11-19.

## Result / 结论

Late Binding solitaire: deal 18 cards in a row; a pile may capture the pile next to it or three places to its left when
the top cards share a suit or a rank; win by reducing everything to one pile. In Stanford's 1989 problem seminar K. A. Ross
asked for the least n such that some n-card start loses for every continuation; Knuth's answer to TAOCP exercise
7.2.2.2–486 records the question, "still unsolved", as whether there is a sequence of (say) nine "poison cards".

- **There is none.** Every 9-card start can be completed to a winning deal (all 34,260,563 patterns of nine cards up to
  renaming suits and ranks; the winning deals were stored and re-verified by an independent program).
- **Thirteen cards suffice:** 5♦ 7♥ 3♦ 6♥ 4♠ A♣ 9♠ Q♣ K♠ J♣ 2♥ 8♦ 10♥ is poison (all 69,090,840 ways to deal the last
  five cards lose). So the least length is between 10 and 13; the 1989 seminar believed it to be at most 17.

Late Binding 纸牌：发 18 张牌成一排，一堆可以压到紧邻左边、或隔两堆的那一堆上（两堆顶牌同花色或同点数），压成一堆即胜。
1989 年斯坦福问题讨论班上 K. A. Ross 问：最少要几张开局牌，才能让之后无论怎么发牌都必输？高德纳在 TAOCP 第
7.2.2.2–486 题答案中称这个问题"仍未解决"：是否存在（比如）九张"毒牌"？

- **不存在。** 任意 9 张开局都能补成能赢的牌局（按花色、点数改名后共 34,260,563 种模式，逐一给出获胜牌局，并由独立程序复核）。
- **13 张就够：** 5♦ 7♥ 3♦ 6♥ 4♠ A♣ 9♠ Q♣ K♠ J♣ 2♥ 8♦ 10♥ 之后无论怎样发剩下 5 张（69,090,840 种）都必输。
  所以最短长度在 10 到 13 之间；1989 年讨论班认为不超过 17。

## Check it yourself / 自行验证

From `source/evidence/` (C compiler only):

```sh
cc -O3 pexh.c -o pexh && ./pexh 1 0 30 19 28 18 3 39 8 50 12 49 14 33 22   # the 13-card poison check, about ten CPU minutes
cc -O3 lbsearch_w.c -o lbsearch_w && ./lbsearch_w 9 10 0 7 w0.bin          # part 0 of 10 of the 9-card witnesses
```

| File | Purpose |
|---|---|
| `quench2.c` | Solver (memoized depth-first search with the suit-rank connectivity cut) |
| `lbsearch.c`, `lbsearch_w.c` | A winning completion for every k-card pattern (the latter stores the 18-card deals) |
| `pexh.c`, `penum.c` | Exhaustive poison checks |
| `hc*.c` | Hill-climbing searches for short poison sequences (`hc4.c`: frozen sequences) |
| `patcount.c` | Numbers of patterns |
| `lb.py`, `validate.py` | Knuth's SAT encoding (exercise 484) and cross-checks of the solver |
| `logs/` | Run logs |
| `verify/` | The independent verifier: its solvers, pattern enumeration and report (`report.txt`) |

## Scope and limitations / 范围与局限

- Not externally peer reviewed. Theorem 1 is a computer proof: one winning 18-card deal for each of the 34,260,563 9-card patterns (two runs with different seeds); the stored deals (617 MB, regenerated by lbsearch_w with seed 7) were re-checked by a separate AI agent with its own solver and its own enumeration of the patterns.
- Theorem 2 is an exhaustive check of all 69,090,840 completions, confirmed by the separate agent with two solvers.
- The exact least length (10 to 13) is not settled.
- Knuth's book and the 1989 report are cited, not reproduced.

本条目未经外部同行评审；结论由独立的 AI 验证代理用自己编写的程序复核。高德纳原书与 1989 年报告只作引用，不转载原文。
