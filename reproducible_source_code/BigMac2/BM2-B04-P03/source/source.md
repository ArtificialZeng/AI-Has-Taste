## DM04-05 六速度族 $(1,4,5,6,7,m)$ 的精确最大孤独度

对每个正整数 $m\notin\{1,4,5,6,7\}$，令
$$L(m)=\max_{t\in\mathbb R/\mathbb Z}\min_{v\in\{1,4,5,6,7,m\}}\|tv\|.$$
求 $L(m)$ 的完整分段有理公式、达到最大值的时刻，并分类何时该六元组 near-tight（即 $1/7<L(m)<1/6$）。

来源与范围：Czerwiński--Grytczuk--Kravitz, *Near-tight lonely runners and the parity phenomenon for six speeds*, arXiv:2609.03444v1，Theorem 6.1、Table 2 与 §6.4。来源列出该五元组加 $m=22,33$ 的 sporadic near-tight 例，但未分析整条一参数族。本题为 source-derived / status-uncertain。精确扫描有限范围或拟合周期不是全称证明；候选分段式必须由碰撞/对踵候选时刻的完整包络或等价证书覆盖全部 $m$。
