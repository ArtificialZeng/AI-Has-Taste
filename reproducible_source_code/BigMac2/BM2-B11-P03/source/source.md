# bigMac-00011-p03 — First noncyclic K-alpha species product

## Immutable source statement

Use the molecular species `K_alpha=X^4/G_alpha` of arXiv:2609.05010v1.  For
`alpha=(2,2)`, so that

`G_alpha=<sigma_2> x <sigma_2> ~= C_2^2`,

determine all integer coefficients `j^lambda_(2,2),(2,2)` in an expansion of
`K_(2,2) x K_(2,2)` in `{K_lambda : lambda |- 4}`.  If this family does not
give a unique expansion, determine a correct minimal basis and all integral
linear relations needed to state the product unambiguously.

## Primary boundary

Baolahy and Randrianirina, *The Molecular Species C_alpha: Geometric
Realization and a Closed Formula for Kronecker Coefficients*,
arXiv:2609.05010v1, Open Problem 5.1, pp. 8--9.  The source treats the
single-cyclic-group case and explains that `K_alpha` requires inversion on the
full subgroup lattice.  The partition `(2,2)` is the first genuinely
noncyclic instance.
