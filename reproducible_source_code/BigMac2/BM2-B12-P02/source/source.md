# bigMac-00012-p02 — The first unresolved Condition-A covering in type D

## Immutable source statement

In the spherical Artin monoid of type `D_4`, use the source's generators
`{σ'_0,σ_0,σ_1,σ_2}` and standard Garside element `Δ`.  Set

`S_1={σ'_0,σ_1}` and `S_2={σ_0,σ_1,σ_2}`.

Prove

`L*(Δ,S)={σ_0,σ_2}=Φ_Δ(S_2⊟S_1)`

and consequently that the proper covering `(S_2,S_1)` satisfies Definition
4.1's Condition A with respect to `Δ^p` for every integer `p>=1`; or give the
least exact `(p,t)` at which Condition A fails.

## Primary boundary

Fromentin and Godelle, *Alternating Decomposition of a Product in a Spherical
Type Artin--Tits Monoid*, arXiv:2609.04757v1, the conjecture in Section 4.3,
p. 19.  For even `r`, the source explicitly predicts this equality for
`i=1` and all-`p` Condition A.  The statement here freezes its smallest case
`r=4`; it does not infer the cases `r>4`.

## Permitted contribution boundary

An exact proof of the displayed `D_4` equality and the stated all-`p`
consequence, or an exact counterexample to either assertion.  Checking only
finitely many powers or alternating depths does not prove Condition A.
