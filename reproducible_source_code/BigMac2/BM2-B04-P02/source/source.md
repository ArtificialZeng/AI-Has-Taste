## DM04-03 二连通非圈图中 $s^+(G)=|V(G)|$ 的等号分类

分类所有有限简单二连通、非圈图 $G$，使邻接矩阵正特征值平方和
$$s^+(G)=\sum_{\lambda_i(G)>0}\lambda_i(G)^2$$
恰等于 $n=|V(G)|$。分类须给出充要结构条件，不只枚举固定阶。

来源与范围：Akbari--Hu--Liu, *Positive and Negative Square Energies of 2-Connected Graphs*, arXiv:2609.04069v1，Theorems 3.4--3.6（PDF pp. 6--7）证明每个二连通非圈图 $s^+(G)\ge n$，但没有分类该非圈等号层。本题为 source-derived / status-uncertain。有限枚举只用于发现或反驳候选分类；完整成果必须把来源证明中顶点删除、Liu--Tang--Zhang 下界和局部能量估计的等号条件闭合。
