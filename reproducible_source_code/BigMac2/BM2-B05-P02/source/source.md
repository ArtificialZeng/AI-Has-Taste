## DM05-02 显式图族 $J_{m,\ell}$ 的 fractional Hamiltonicity 精确阈值

令 $H_m$ 由完全图在顶点 $\{a,b_1,\ldots,b_m\}$ 上的每条边 $ab_i$ 各细分一次得到，细分点为 $x_i$；令
$$J_{m,\ell}=K_\ell\vee H_m.$$
对全部整数 $m\ge2,\ell\ge1$，分类 $J_{m,\ell}$ 何时 fractionally Hamiltonian。等价地，对来源定义的 cut linear program $(P)$ 精确求最优值，并给出完整参数阈值及边界等号证书。

不得把对有限参数的 rational LP 计算当作全参数证明，也不得把 non-RN 与 non-fractionally-Hamiltonian 混同；来源只证明前者的一个参数区间。允许的最小完整贡献是：一个定义封闭的无限参数分支之充要分类，或一个精确反例推翻自然阈值。

来源与范围：Flammant, *Toughness Bounds for Fractional Hamiltonicity and Resistance Positivity*, arXiv:2609.03412v1, Lemma 7 and Propositions 15--16（PDF pp. 5, 11--13）。来源证明 $\tau(J_{m,\ell})=1+\ell/m$ 且 $m\ge2\ell+4$ 时 $J_{m,\ell}$ 不 resistance nonnegative，但未分类该族的 fractional Hamiltonicity。本题因此是 source-derived / status-uncertain，而不是来源明列的开放定理。
