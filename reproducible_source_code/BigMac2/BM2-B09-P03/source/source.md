# bigMac-00009-p03 — Exact order-four almost-Sarymsakov horizon

## Immutable source statement

Use Definition 3 of arXiv:2609.05050v1 with one fixed common ordering.  For the
class `T_AS(4)` of all order-four almost-Sarymsakov stochastic matrices, determine
the exact uniform scrambling horizon

`h_scr(T_AS(4)) = min{h : every h-factor product from T_AS(4) is scrambling}`.

The result must cover arbitrary positive weights compatible with every admitted
support, not a sampled numerical subclass.

## Primary boundary

Hsu, *Sarymsakov-Type Semigroups With Support Dominance and Nested Mixing
Cores*, arXiv:2609.05050v1, Definition 3, Theorem 5 and Remark 5, pp. 5--6.
The theorem gives `h_scr(T_AS(4))<=18`; sharpness is proved only for order three.

## Permitted contribution boundary

An exact value with (i) a longest non-scrambling Boolean support word and (ii) a
complete upper-bound certificate over every legal support pattern.  Floating
matrix products or a search that omits support patterns are not sufficient.
