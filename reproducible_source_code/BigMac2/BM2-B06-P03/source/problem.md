# 精确问题解释

## 冻结对象与定义

本项目只研究 `source.md` 中写出的命题；原文保持不变。令 \(q\) 为形式变量，并在
形式幂级数环 \(\mathbb Z[[q]]\) 中解释所有恒等式。记
\[
(a;q)_\infty:=\prod_{j\ge 0}(1-aq^j),\qquad
f_d:=(q^d;q^d)_\infty=\prod_{m\ge1}(1-q^{dm}).
\]
定义整数序列 \(b(N)=\bar b^{\,2}_{4,4}(N)\)（\(N\in\mathbb Z_{\ge0}\)）为
\[
F(q):=\sum_{N\ge0}b(N)q^N=\frac{f_2^8}{f_1^{16}}.
\]
每个系数只涉及有限多个 Euler 因子，因此该定义在 \(\mathbb Z[[q]]\) 中良定。
逐因子约分还给出
\[
F(q)=\prod_{m\ge1}\frac{(1-q^{2m})^8}{(1-q^m)^{16}}
    =\prod_{m\ge1}\left(\frac{1+q^m}{1-q^m}\right)^8.
\]

## 待判定的精确命题

冻结命题 \(C\) 是
\[
\forall n\in\mathbb Z_{\ge1},\qquad b(5n)\in5\mathbb Z.
\]
等价地，若 \(U_5F:=\sum_{n\ge0}b(5n)q^n\)，则
\[
U_5F\equiv1\pmod5
\quad\text{在 }(\mathbb Z/5\mathbb Z)[[q]]\text{ 中}.
\]
常数项 \(b(0)=1\)，所以 \(n=0\) 明确不在原命题量词范围内。这里的同余是整数
系数同余，不依赖解析收敛。

完整证明必须覆盖每个 \(n\ge1\)。反驳只需给出一个 \(n\ge1\)，并从上述冻结
Euler 乘积精确算出 \(b(5n)\not\equiv0\pmod5\)。本项目不包含 Conjecture 7.1
中的其他同余，也不把有限范围无反例当作普遍证明。

## 来源核对与范围差异

2026-09-06 核对 arXiv:2609.03926v1 的 HTML 主文
(<https://arxiv.org/html/2609.03926>)：式 (1.2) 为
\[
\bar B^k_{r,s}(q)=\frac{f_2^{(3s-2r)k}}
{f_1^{2sk}f_4^{(s-r)k}}.
\]
代入 \((r,s,k)=(4,4,2)\) 确实得到冻结乘积 \(f_2^8/f_1^{16}\)。但是该文
Conjecture 7.1 实际列出的是
\(\bar b^{\,4}_{4,4}(5n)\equiv0\pmod5\)，即上标 \(k=4\)，而不是冻结题的
\(k=2\)。所以 `source.md` 对 Conjecture 7.1 的归属存在实质性参数错配；不能
静默把冻结题改成 \(k=4\)。最近的已定位来源是这个不同参数的计算猜想，并非
冻结命题的既有定理。本次仅核对该首要来源，未声称完成穷尽性文献检索。

## 最廉价判别测试的结果

令
\[
A(x)=\left(\frac{1+x}{1-x}\right)^8
=1+16x+128x^2+688x^3+2816x^4+9424x^5+O(x^6).
\]
由 \(F(q)=\prod_{m\ge1}A(q^m)\)，按 \(5\) 的七个整数分拆逐项取系数可得
\[
\begin{aligned}
[q^5]F
&=9424+(688)(16)+(128)(16)+(16)(128)\\
&\quad +(16)(16)+(16)(16)+16\\
&=25056\equiv1\pmod5.
\end{aligned}
\]
因此 \(n=1\) 是冻结命题的精确候选反例。`evidence/triage_b5.py` 以截断至
\(q^5\) 的整数运算分别从未约分 Euler 乘积及约分乘积复算此值。该发现仍需
后续新鲜审计后才能提升为正式数学判定；它不反驳论文中参数不同的 \(k=4\)
猜想。

## 目标贡献与验证路线

最近来源：Thejitha--Fathima 的 \(k=4\) 计算猜想。冻结题的拟议增量：严格
指出参数错配，并以 \(b(5)=25056\) 反驳单独冻结的 \(k=2\) 命题。验证路线：
