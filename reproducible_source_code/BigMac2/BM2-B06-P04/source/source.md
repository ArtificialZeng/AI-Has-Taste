## DM06-04 \(e=6\) charged-bipartition 核心生成函数的全系数正性

严格采用 Gerber--Norton 对 charged bipartitions、\((e,\mathbf s)\)-cores
及生成函数 \(c_{e,\mathbf s}(q)\) 的定义。证明或反驳：
\[
 [q^n]c_{6,(0,1)}(q)>0
 \quad\text{且}\quad
 [q^n]c_{6,(0,3)}(q)>0
 \qquad\text{对每个整数 }n\ge0.
\]

先从来源式 (5.3) 独立核对两个生成函数，不能凭转录猜公式。有限系数
计算只能用于反例搜索或发现正项分解；完整正向贡献须给 theta/partition
表示、递推或其他覆盖所有次数的严格证明。若两者只有一个被解决，只能
作为明确局部结果送审，不得宣布完成合取原题。

来源：Gerber--Norton, *Enumerating cores of charged multipartitions*,
arXiv:2609.03738v1, Conjecture 3.10、equation (5.3) 与 Table 2
（PDF pp. 29--30, 43）。来源证明奇数 \(e\) 和 \(e=4\) 的相关分支，并
明确说明 \(e=6\) 缺口等价于上述两个正性陈述，目前仅有计算支持。
