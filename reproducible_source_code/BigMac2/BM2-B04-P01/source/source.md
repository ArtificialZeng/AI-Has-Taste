## DM04-01 六点 Lorentzian 矩阵上的有界比率常数是否仍至多 2

对每个归一化 reduced bounded ratio $\alpha\in-\mathrm{Cut}_6^\vee\setminus\{0\}$，缩放使 $\sum_{i<j}\alpha_{ij}=-1$。令 $f(\alpha)$ 是所有对角元为 $1$、元素严格为正且至多一个正特征值的实对称 $6\times6$ 矩阵 $P=(p_{ij})$ 上
$$\prod_{i<j}p_{ij}^{\alpha_{ij}}$$
的上确界。证明或反驳 $f(\alpha)\le2$；若为真，分类等号 extreme rays。

来源与范围：Baldi--Kummer, *A Note on Bounded Ratios*, arXiv:2609.03934v1，Conjecture 3.1 及其后讨论（PDF pp. 3--4）。来源证明原猜想在 $n\le5$ 成立，并用 $\mathrm{Cut}_7$ 的非 hypermetric clique-web facet 给出 $n=7$ 反例；它指出 $\mathrm{Cut}_6$ 除五点提升外只有两个新的 hypermetric facet 型，但只说作者未找到反例。因此本题为 status-uncertain；不得把作者未找到反例写成开放性或正确性证明。一个完整正解须核验两个新 facet 型的全半代数可行域，数值优化不构成证明。
