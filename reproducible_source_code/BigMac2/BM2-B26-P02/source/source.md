# bigMac-00026-p02 — order-eight fixed-start cover-time equality

## Immutable source statement

For every connected non-tree simple graph `G` on exactly eight vertices,
every genuine nonedge `uv`, and every starting vertex `s`, determine whether
\[
t_{\rm cov}(G+uv,s)\ne t_{\rm cov}(G,s).
\]
Either prove this finite universal statement or give an explicit equality
instance.

An equality certificate must contain the graph, `u,v,s`, and independently
checkable exact rational cover times. A no-equality result must cover all
11,094 connected non-tree isomorphism classes of order eight, every nonedge,
and every start, with a complete graph inventory, exact arithmetic, run
metadata, hashes, and a structurally independent verifier. This statement is
only the fixed-start order-eight layer; it does not include the worst-start
conjecture and does not assert the unrestricted theorem.
