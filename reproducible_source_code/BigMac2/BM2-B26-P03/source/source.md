# bigMac-00026-p03 — weak-EKR classification for `GL(3,2)`

## Immutable source statement

Let `V=F_2^3`. Classify, up to conjugacy in `GL(3,2)`, all irreducible
subgroups `L<=GL(3,2)` for which the following implication holds for every
linear subspace `W<=V` and every subset `A subseteq V`:
\[
A-A\subseteq\bigcup_{\ell\in L}W^\ell
\quad\Longrightarrow\quad |A|\le |W|.
\]
For every class that fails, provide an explicit triple `(L,W,A)`; for every
class that passes, provide exhaustive exact evidence. The classification must
also certify the completeness of the subgroup-conjugacy list and
irreducibility tests, not merely test a selected collection of subgroups.
