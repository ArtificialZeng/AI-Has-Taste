# Focused literature check (2026-09-09)

The primary source was checked at
<https://arxiv.org/html/2608.18594> (arXiv:2608.18594v1, 2026-08-19).
Its displayed formula at lines 141--145 is the implication frozen in
`source.md`; Proposition 2.6 treats rank two; and Problem 2.9 at lines 206--213
asks for a characterization when `d >= 3`. It does not state the present
`(d,p)=(3,2)` classification.

A focused search for the exact terms `GL(3,2) weak EKR`, `F_2^3 weak EKR`, and
`irreducible GL(3,2) Erdős--Ko--Rado` found no separate primary source asserting
this finite classification. This is a search report, not a proof of priority or
novelty.

For comparison, Ernst--Schmidt, *Transitivity in finite general linear groups*,
Mathematische Zeitschrift 307 (2024), article 52,
<https://doi.org/10.1007/s00209-024-03511-x>, surveys classifications of
subgroups transitive on linear-space configurations (Section 4). It supplies
useful surrounding linear-group context, but the inspected theorem does not
state the weak-EKR classification here. The present exact subgroup certificate
is therefore retained as the decisive classification evidence rather than
claiming that the group list is new.

Limit: this bounded search was focused, not a systematic review of every finite
group census or difference-set database. No unconditional priority claim is
made.
