# bigMac-00027-p04 — order-eight generating group distance-magic layer

## Immutable source statement

Classify all regular ordinary distance-magic graphs `G` on exactly eight
vertices with respect to the following assertion:

> `G` admits a generating `(Z/2Z)^3`-magic map.

Here an ordinary distance-magic graph admits a bijection
`ell:V(G)->{1,...,8}` with constant integer open-neighborhood sum.  A
`Gamma`-magic map has constant open-neighborhood sum in `Gamma`, and it is
generating when its labels generate `Gamma`; bijectivity and affine generation
are not required.

Using the cited source's reduced modular adjacency operator `A_2`, the assertion
for `Gamma=(Z/2Z)^3` is equivalent to an embedding

\[
(Z/2Z)^2\hookrightarrow\ker A_2,
\]

or `dim_{F_2} ker A_2>=2`.  A complete positive answer must enumerate all
unlabeled regular ordinary distance-magic graphs of order eight, certify the
ordinary labelings and isomorphism coverage, and verify the kernel bound.  A
negative answer must give one graph, an ordinary distance-magic labeling, and
an exact rank certificate.  The nonregular eight-vertex example in the source
is outside this frozen target.
