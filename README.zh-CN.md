# AI Has Taste

![Taste? — AI and the Fields Medal tradition in a symbolic mathematical duel](assets/ai-has-taste-hero.png)

**从生成答案，到生成研究议程**

**200+ 数学开放问题 · 证明 · 反驳 · AI 自主提出的猜想**

> **AI 能否决定：下一步，什么数学值得研究？**

解出一道题，是一种智能。选出下一个值得研究的问题，是另一种。

这个项目探索的，正是第二道边界。在人类设定的目标与约束之内，AI agent 筛选课题、打磨命题、设计决定性测试、寻找证明与反例，也在路线失败时改变方向。有些研究得到了定理，有些刻画了方法的局限，还有一项研究形成了新的、可证伪的猜想，并建立了通向原问题的条件性路径。

**系统不只参与研究的执行，也参与研究方向的选择。**

这就是 **AI Has Taste** 的含义：它不是关于意识的宣言，而是关于**通过研究决策显现出来的数学判断力**。

*证明回答一个问题。猜想划出下一道边界。*

**源码可用范围：** 原有 Smallmac PDF 的源码可用状况不变；本次不新增 Smallmac 源码包。BigMac1 沿用既有的 LaTeX 仅本地保留策略；BigMac2 的完整配套 LaTeX 副本也保留在本地，并附经过筛选的复现材料及各包限制。现有 Git 规则排除 LaTeX，本地可用不表示对应路径将上传 GitHub。当前是本地待确认版，尚未上传。

<details open>
<summary><strong>真正的转变：从解答问题，到选择下一步</strong></summary>

<a id="research-shift"></a>

常见的 AI 评测，往往在最关键的选择已经完成之后才开始：已经有人决定，哪个问题值得回答。

数学研究开始得更早，也不会在第一次尝试失败时结束。哪个命题值得精确化？哪次计算能决定下一步？反例只是摧毁了一条路线，还是揭示了真正成立的定理？一个较小的成果何时已足够有价值，应当停止扩张、开始审查？

这些是关于品味的问题，也是能够留下记录的研究决策。

在这个档案记录的流程里，agent 并非只被要求为一个固定答案辩护。它们可以在候选之间取舍，放弃不再产生信息的路线，提炼有用的主张，再把主张交给另一个上下文独立攻击。精确证据能够改变研究方向。

这里的递进不是**更多提示词 → 更多 PDF**，而是：

**选择问题 → 测试路线 → 找到断点 → 识别结构 → 修改问题 → 证明或提出猜想 → 尝试证伪 → 审查精确主张。**

并非每项研究都走完这条链，也并非每篇 PDF 都解决了原题。真正重要的变化在于：下一步数学行动，可以从研究本身生长出来。

**从生成答案，到生成研究议程。**

</details>

<a id="research-trajectories"></a>

最有说服力的证据，不是档案有多厚，而是一条数学路线走不通之后，发生了什么。

<details>
<summary><strong>01 · 一个公式失效，一个最优常数成为新目标</strong></summary>

<a id="trajectory-1"></a>

Tang–Zhang 提出的 Schatten 范数公式是起点。精确反例表明，它在低于 Hilbert 指数的范围内失效。后续研究没有停在“错误”二字，而是转向指数 $3/2$ 下两个秩一矩阵的最优常数，得到了精确值与等号分类。

这并没有解决原先的任意秩问题。但它呈现了一次有实质意义的问题转换：**从检验一个候选公式，到找出在它失败之后依然成立的最优定理。**

证据：[SM1-P01 · 候选公式的反例](pdfs/smallmac_1/SM1-P01_Tang_Zhang_Schatten_Norm_Formula.pdf) · [SM1-P02 · 精确的 Schatten $3/2$ 常数](pdfs/smallmac_1/SM1-P02_Exact_Schatten_Three_Halves_Constant.pdf)。

</details>


<details>
<summary><strong>02 · 一条计数路线遇阻，方法局限成为定理</strong></summary>

<a id="trajectory-2"></a>

一个精确的 Lehmer 签名图引出了有界前瞻方法：能否用固定长度的后续信息，区分计数所需的状态？

论文构造了这样的状态：在任意指定长度之前，所有后续行为都一致，却恰好在那个长度分开。**路线的失败，转化成了针对这一特定方法的无限族障碍定理。**

这没有排除所有计数算法，原始枚举问题仍未解决。它用一个后续研究必须尊重的精确边界，替代了不再有效的路线。

证据：[SM2-P18 · 可任意延迟的后续分裂](pdfs/smallmac_2/SM2-P18_Arbitrarily_Delayed_Continuation_Splits_in_an_Exact_Lehmer_Signature_Graph.pdf)。

</details>


<details>
<summary><strong>03 · 证明路线失败，却揭示了一个新猜想</strong></summary>

<a id="trajectory-3"></a>

在分数 Gaussian 迹问题中，基于单调性与单侧配对的证明尝试遭遇了精确反例。这些失败指向了一个不同的研究对象：固定的负缺陷。

研究提炼出一个**十项修正多项式**，证明在指标 13 时，每一个系数就已不可缺少，并建立了条件性结论：如果该缺陷满足所提出的一致界，原始迹比较便随之成立。随后，新命题接受了精确计算攻击与单独的猜想审查。

存档扫描达到指标 1004。独立重建只覆盖论文明确列出的较小范围，并未独立复现整段扫描。**这个一致界仍然没有被证明。**

也正因如此，这段过程值得研究。它既不是编造的成功，也不是一句空泛的“未来可以继续探索”，而是一个精确、有推论、有通路回到原问题，并且能够被测试推翻的命题。

**这项研究不只产生了答案，也产生了下一个问题。**

证据：[SM2-P11 · 分数 Gaussian 迹的最优固定缺陷猜想](pdfs/ai-conjectures/SM2-P11_A_Sharp_Fixed_Defect_Conjecture_for_Fractional_Gaussian_Traces.pdf)。

</details>

<details>
<summary><strong>多 Agent 研究：把质疑放进流程本身</strong></summary>

<a id="multi-agent-workflow"></a>

这里的自主性，不等于没有人类方向。人类定义目标、约束与权限；在这一框架内，不同的 agent 角色承担选题、研究、批评与成稿工作：

1. **监督与初筛：** 选择候选，对照邻近结果，确定成本最低且有判别力的下一测试。
2. **研究：** 寻找证明与反例，区分精确证据、有限观察与猜想。
3. **全新上下文数学审查：** 攻击冻结后的命题、关键引理、证书与所声称的贡献。
4. **成文与发布检查：** 准确呈现被接受的范围，检查当前文稿、引文与构建。

持久化记录、冻结主张与明确证据连接这些角色。研究者不能简单地为自己的成功盖章。一个被退回的论证可以改变下一任务；一个有价值的局部结果也可以结束研究，而不冒充原问题的完整解答。

**批评不是最后的附言，而是推动研究的一部分。**

全新 AI 上下文的审查，不是外部同行评审。脚本运行成功，也不等于证明了它未曾检查的陈述。这些区分是项目可信度的组成部分，并非故事的例外。

<summary><strong>这些主张意味着什么，又不意味着什么</strong></summary>

<a id="reading-the-claims"></a>

**请看贡献，而不只看标题。** 目录区分指定问题的完整解答、受限范围内的定理、反例、有限证书、替代证明、结构性归约与猜想。特殊情形的证明不能解决其母猜想；有限范围内未出现，也不能证明永远不可能出现。

PDF 是文稿，不是“已解决数学问题”的计量单位。重查已有证据不构成发现优先权。内部审查接受的结果，也不自动等于期刊发表或历史上首次出现的新定理。

Smallmac 2 提供 **109 篇当前流程发布稿与 8 篇历史文稿**，其中一篇历史文稿归入猜想目录。Smallmac 1 提供 **17 篇文稿**。**SM1-P04** 中依赖关键外部结果的完整证明主张，仍明确标注为需要独立复核。

这个仓库保留存档主张及其限制。制作目录**不是一次新的证明审计**。内部审查、外部同行评审与形式化验证是不同层次的证据，不能混为一谈。

**品味不是靠宣称每次尝试都成功来证明的。它体现在研究选择了什么、改变了什么，以及诚实地留下了什么尚未解决。**
